WARDEN DAY 4
============

These are the Day 4 files. They go INTO your existing WARDEN-SEPT15 folder.

Do NOT keep this as a separate folder. A separate folder becomes a separate
git repo, which is what made the push fail last time.


WHAT TO DO
----------

1. Extract this zip somewhere (Desktop is fine).

2. Open the extracted WARDEN-DAY4-FILES folder.

3. Press Ctrl+A to select everything, then Ctrl+C to copy.

4. Open your WARDEN-SEPT15 folder.

5. Press Ctrl+V to paste.

6. Windows will ask about duplicates. Choose "Replace the files in the
   destination".

7. In WARDEN-SEPT15, double-click START WARDEN.bat.
   Press 2 to run the tests. You want 44 passed, 0 failed.
   Press 6 to run Warden against the real filesystem MCP server.

8. Double-click PUSH TO GITHUB.bat to save it.

9. You can delete WARDEN-DAY4-FILES afterwards.
